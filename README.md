# 20261125 DIC 4 — Moto Touring Copilot

This repository contains the IEEE-style proposal manuscript for **Moto Touring Copilot: A Multi-Agent Motorcycle Touring Planning System with Personalized Pace Prediction and Deterministic Verification**.

## Project structure

- `ICEIB2027-IEEE/main.tex` — main LaTeX document
- `ICEIB2027-IEEE/sections/` — manuscript sections
- `ICEIB2027-IEEE/tables/` — reusable tables
- `ICEIB2027-IEEE/references.bib` — BibTeX references
- `ICEIB2027-IEEE/figures/` — figure assets

## Build

Set `ICEIB2027-IEEE/main.tex` as the root document and compile with pdfLaTeX and BibTeX. The project is also maintained in Overleaf.

## Status

The manuscript currently contains five pages and compiles successfully without LaTeX errors or warnings. It remains at the proposal stage; experimental results are pending.
